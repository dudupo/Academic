

\begin{abstract}
We are studying the depth complexity of the realization of the logical $T$ gate for the Toric code. Here, we consider a quantum circuit composed of bounded fan-in elementary gates for which classical depth matters, namely only constant classical depth is allowed per physical time unit. In addition, we allow the input to contain any resource state and set no restriction on the output state over the auxiliary space except that it must be in a tensor product with the main register.
\end{abstract}
